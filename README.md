Using EEG spectral data to predict circadian state index, and thus classifying sleep as healthy or unhealthy. I used the 'Resting-state EEG Dataset for Sleep Deprivation', available at https://doi.org/10.18112/openneuro.ds004902.v1.0.4 . Completed as part of our project for the Imperial NeuroTech Hackathon 2026.
